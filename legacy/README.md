# BAAC DCM Tracker

ระบบต้นแบบสำหรับ LINE Official Account: บันทึกลูกค้า → รออนุมัติ → รายการอนุมัติแล้ว

รุ่นแรกมีเฉพาะชื่อ นามสกุล และ CIF ไม่มีข้อมูลสัญญาหรือวงเงิน หัวหน้าฝ่ายสินเชื่อ/หัวหน้าหน่วยเป็นบทบาทเดียวกัน ผู้ช่วยผู้จัดการสาขาหรือผู้จัดการสาขาคนใดคนหนึ่งอนุมัติได้ ไม่ต้องอนุมัติต่อกันสองขั้น

## ทดลองในเครื่อง

ใช้ Node.js 24 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```bash
cd /workspace/BAAC-DCM-Tracker
npm test
npm run dev
```

โหมดทดลองฟังเฉพาะ 127.0.0.1:3000 ใช้ข้อมูลสมมติเท่านั้น เลือกบทบาทจากหน้าจอเพื่อทดลองครบวงจร ข้อมูลบันทึกใน SQLite ที่ `data/tracker.sqlite` (ไม่รวมใน Git) ต้องสำรองฐานข้อมูลตามนโยบายของหน่วยงาน โหมดจริงไม่ยอมรับการสลับบทบาทจากเบราว์เซอร์

## เชื่อม LINE จริง

1. จัดเตรียม HTTPS hosting สำหรับ Node.js พร้อมพื้นที่ SQLite แบบถาวร ตั้ง `DEMO_MODE=false` แยกฐานข้อมูลทดลองออกจากฐานข้อมูลจริง
2. สร้าง LINE Login channel และ Messaging API channel ภายใต้ provider เดียวกัน เพื่อให้ LINE user ID ตรงกัน เพิ่ม LIFF app พร้อม scope `openid` และ `profile` โดยตั้ง Endpoint URL เป็น HTTPS URL ของแอป
3. คัดลอก `.env.example` เป็น `.env` (ไฟล์นี้ถูก ignore) แล้วตั้ง `LIFF_ID`, `LINE_LOGIN_CHANNEL_ID` และ `APP_URL` ผ่านการตั้งค่าที่ปลอดภัยของ hosting ห้าม commit รหัสลับ
4. กำหนด `LINE_USERS_JSON` เป็น JSON ที่แมป LINE user ID ไปยัง `credit_head`, `assistant_manager` หรือ `manager` ใช้ user ID จริงของเจ้าหน้าที่เท่านั้น ผู้ใช้ที่ไม่ได้กำหนดจะถูกปฏิเสธ การอนุมัติบันทึกผู้อนุมัติและเวลา
5. หากใช้ webhook ให้ตั้ง `LINE_CHANNEL_SECRET` และ URL `/webhook` ใน Messaging API console ปัจจุบัน webhook ตรวจลายเซ็นและตอบรับเท่านั้น ไม่ส่งข้อความหรือบันทึกข้อมูลจากแชต
6. รัน `npm start` ทดสอบการเข้าใช้งาน LIFF ด้วยบัญชีจริงครบทุกบทบาทก่อนเปิดให้ใช้
7. ตั้ง Rich Menu ใน LINE Official Account Manager เป็น 3 ช่อง โดยแต่ละช่องลิงก์ไปที่ `https://liff.line.me/<LIFF_ID>?page=create`, `?page=pending`, `?page=approved` ตามลำดับ ใช้ชื่อ “บันทึกลูกค้า”, “รออนุมัติ”, “รายการอนุมัติแล้ว” ทุกคนอาจเห็นเมนูเดียวกัน แต่เซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำขอ

ทางเลือก API: `npm run line:menu` สร้างโครงเมนูเมื่อกำหนด `LINE_CHANNEL_ACCESS_TOKEN` และ `APP_URL` แล้วเท่านั้น ต้องตั้ง APP_URL เป็น LIFF entry URL หากต้องการเปิดใน LIFF สคริปต์ยังไม่อัปโหลดภาพหรือผูกเมนูกับผู้ใช้ ต้องเตรียมภาพขนาด 2500×843 และตรวจสอบก่อนเปิดใช้งานจริง

## ข้อจำกัดของต้นแบบ

- รองรับสาขาเดียว รายการล่าสุดสูงสุด 200 รายการ ไม่มีค้นหา แก้ไข ปฏิเสธ หรือแจ้งเตือนผ่านแชต
- ห้ามสร้างรายการรออนุมัติ CIF ซ้ำ แต่สร้างรายการใหม่สำหรับ CIF เดิมได้หลังรายการเก่าอนุมัติแล้ว
- ต้องทดสอบ LINE จริงและจัดเตรียม HTTPS, การสำรองข้อมูล, การควบคุมสิทธิ์และการดูแลข้อมูลลูกค้าก่อนใช้ข้อมูลจริง
- ไม่ได้สร้างหรือเผยแพร่ Rich Menu ไปยัง LINE โดยอัตโนมัติ

## ตรวจสอบ

`npm test` ทดสอบการบันทึก การอนุมัติ สิทธิ์ ข้อมูลผิดรูปแบบ CIF ศูนย์นำหน้า รายการซ้ำ และลายเซ็น webhook โดยไม่ติดต่อ LINE จริง
