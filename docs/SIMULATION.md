# ผลการจำลองการใช้งาน

เพิ่มพื้นที่ทดลองเฉพาะผู้ดูแลที่ `/sandbox` บน Worker ที่ใช้อยู่แล้ว ต้องยืนยันตัวตนผ่าน LINE ก่อนเลือกบทบาท แต่ไม่ต้องมี LINE ของเจ้าหน้าที่ตำแหน่งอื่น ใช้ D1 คนละฐานกับข้อมูลลูกค้าจริง ไม่มีการส่งข้อความ LINE หรือเปลี่ยน Rich Menu ระหว่างทดสอบ

## ข้อมูลพร้อมลองบน Cloudflare

- ลูกค้าสมมติ 15 ราย ชื่อ “ลูกค้าทดสอบ01” ถึง “ลูกค้าทดสอบ15” นามสกุล “นามสกุลสมมติ”
- CIF `00001001` ถึง `00001015` โดยเริ่มรออนุมัติ 10 ราย และอนุมัติแล้ว 5 ราย
- บทบาทหัวหน้าฝ่ายสินเชื่อ ผู้ช่วยผู้จัดการ ผู้จัดการ ผู้ดูแล และเจ้าหน้าที่รอรับสิทธิ์
- ผู้ดูแลสลับบทบาทจากแถบ “พื้นที่ทดลอง” เพื่อดำเนินงานครบวงจรได้ การเลือกบทบาทไม่เปลี่ยนตำแหน่งหรือสิทธิ์จริงของตน

## ตรวจแล้ว

ชุดอัตโนมัติ `npm test` ผ่าน 13 tests ครอบคลุมการบันทึก อนุมัติซ้ำ สิทธิ์ ค้นหา แบ่งหน้า คงข้อมูลหลัง restart การตรวจ LINE token ลายเซ็น webhook และการไม่ปะปนฐานข้อมูล การเรียก LINE และ Cloudflare ใน unit tests เป็น mock

ทดสอบด้วย Chromium ผ่านหน้าจอ simulator แบบมือถือ 12 สถานการณ์:

1. เปิดพื้นที่ทดลองและเลือกบทบาท
2. บันทึกลูกค้าสมมติ
3. ป้องกัน CIF ซ้ำขณะรออนุมัติ
4. กดย้อนกลับในหน้าต่างยืนยันแล้วรายการยังรออนุมัติ
5. ผู้ช่วยผู้จัดการอนุมัติ พร้อมชื่อผู้อนุมัติและเวลา
6. ผู้จัดการสาขาอนุมัติ
7. ค้นหา CIF โดยคงศูนย์นำหน้า
8. Reload แล้วยังเห็นประวัติ
9. บัญชีรอรับสิทธิ์เข้าใช้งานรายการไม่ได้
10. ผู้ดูแลเปิดสิทธิ์ให้บัญชีทดลองแล้วใช้ได้
11. ผู้ดูแลระงับบัญชีทดลองแล้วใช้ไม่ได้
12. ไม่พบ JavaScript error ระหว่างทดสอบ

รายละเอียดการรันปัจจุบันเก็บใน `simulation-results.json` ภาพอยู่ใน `screenshots/trial-pending.png` และ `screenshots/trial-approved.png`

ตรวจบน Cloudflare จริงแล้วว่า `/sandbox` กับ config ตอบสำเร็จ, ข้อมูลทดลองมีใน D1 แยก, API ทั้งระบบจริงและทดลองปฏิเสธผู้ที่ยังไม่เข้าสู่ระบบด้วย 401 และจำนวนลูกค้าจริงก่อน/หลังเติมข้อมูลทดลองเท่ากัน คงบัญชีผู้ดูแลเดิมไว้ การลองกดด้วย LINE ของเจ้าของบัญชีในพื้นที่ทดลองใหม่ยังให้ผู้ใช้ยืนยันเองหลังเปิดหน้าเว็บ (ผู้ช่วยไม่ได้เข้าบัญชี LINE แทนผู้ใช้)

## ลองด้วยตัวเอง

เปิด LIFF เดิมแล้วกด “เปิดพื้นที่ทดลอง” ในหน้าผู้ดูแล เลือก “หัวหน้าฝ่ายสินเชื่อ” แล้วบันทึกลูกค้าสมมติ เช่น CIF `00112233` จากนั้นเลือก “ผู้ช่วยผู้จัดการสาขา” → รออนุมัติ → อนุมัติรายการ → อนุมัติแล้ว จะเห็นรายการที่เพิ่งทำพร้อมชื่อและเวลา

อย่าใส่ข้อมูลลูกค้าจริงในพื้นที่นี้ ข้อมูลที่ทดสอบคงอยู่เพื่อให้กลับมาลองต่อได้ ไม่ได้รีเซ็ตทุกครั้งที่เปิดหน้า
